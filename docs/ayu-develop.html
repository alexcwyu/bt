Purpose and scope

Simulate a tree of portfolio strategies and securities using composable algorithms and date-indexed prices.

Design decisions

Decision Rationale Tradeoff Evidence
A tree models portfolios and nested strategies. Each node participates in shared update and transaction accounting. Execution is date-based and direct transaction accounting rather than venue messaging. Strategy.run (L2267) / SecurityBase.transact (L1762)

Strengths and limits

Strengths

  • Composable algorithms can short-circuit while mandatory run_always operations continue. AlgoStack.call (L2209)

Limitations

  • User-supplied prices and modeled costs determine historical accounting. External order acknowledgements are not modeled by transact. SecurityBase.transact (L1762)
